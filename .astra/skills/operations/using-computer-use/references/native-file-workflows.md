# 文件与桌面工作流

仅用于相应 Finder/WPS 文件任务，通用授权、未知结果不重放及当前工具能力约束仍适用。

- Finder 关闭标签可优先考虑已观察到的 `AXMenuItem`「关闭标签页 / Close Tab」。先确认目标标签当前已选中；多个标签时菜单作用于当前标签，不能用「关闭窗口」「关闭其他标签页」替代。必要时先选择目标标签并核验，再用新快照的菜单 ref。菜单被截断时可用 `computer_snapshot(role_filter="AXMenuItem")`；这不是恢复 helper 未采集的节点。

- 保存需核验实际目标文件及内容，不能只看保存按钮回执。另存为弹窗出现后绑定它的新 refs；已请求的文件目标、覆盖规则和 once 审批保持有效边界，不能为了测试保存到个人文稿目录。新 ref 仍反复 stale 时停止输入并报告，不反复试同一批次。

- Finder 滚动优先检查目标内容区域的 `AXScrollBar` 子节点：已观察到且支持 `AXPress` 的 `AXIncrementPage`（下一页）/ `AXDecrementPage`（上一页）可用 `click(element_ref=...)` 做语义翻页。必须核对父滚动条属于目标列表，不能误点侧边栏；用新快照逐页操作并核验滚动值/可见行。子按钮缺失时，可先用 `role_filter="AXScrollBar"` 定位目标滚动条，再以最新返回的滚动条 ref 作 `subtree_ref` 观察子按钮；role_filter 本身不会保留不同角色的子节点。`action_observation` 的 `matching_scrollbar_value_changed` 仅说明该滚动条数值变化，不保证目标内容已到达。

- 滚动条没有 AXIncrement/AXDecrement 时，不假设 `scroll(element_ref=...)` 会走原生滚动。指针滚动无效果或 `out_of_bounds` 时，不放宽边界，也不重复滚轮试探；另选已观察到的原生翻页按钮。找不到对应控件则报告能力缺口，未知结果仍遵守 no-replay。

- 另存为的文件名与目标目录分别核验：不要向文件名框输入绝对路径来代替目录导航，WPS 会把斜杠转成冒号并仍保存到当前目录。先通过受支持的目录导航确认位置，再只输入文件名；无法确认目标目录时停止保存。

- 保存到已有目录时，优先读取“位置”菜单中的当前路径和可用目录项；选择后重读位置，再核对上级路径，防止同名目录误判。已实测最近目录菜单切换、上级路径核对及英文文件名实际保存；未列出的任意目录仍须使用另一个已验证的导航方式，不能用文件名绝对路径冒充。

- WPS 的“新建文件夹”等附属弹窗可能标题为空；使用 fresh catalog 中精确匹配、bindable 的子窗口 refs，不继续操作被遮挡的父窗口。已实测新建目录→核验位置→中文文件名→保存及格式确认可完成；弹窗关闭返回 unknown_outcome 时先观察新窗口和实际文件，不重放点击。command+shift+g 尚未验证有效，不作为目录导航方式。

- WPS 另存为文件名输入：ABC 输入源下曾实测写入中文并保留未选中的扩展名，但后续也出现中文输入回执成功而值不变；ABC 不保证成功。SCIM 中文输入源也有该现象。遇到这种情况报告输入路径兼容性限制，交给用户切换 ABC，再以新会话/新快照做明确的新输入；不自动切输入法、不放宽 IME 保护，不把先前未知动作自动重放。

- 中文 Unicode 文本写入与输入法候选操作分别验收；前者成功不代表候选窗可操作。滚动需比较目标区域可见内容或滚动值，页面无变化也可能已在边界，先确认方向与当前位置。
